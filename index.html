DECODING BRIEF

Reveal the image from left to right

Use R or Python. Do not resize, crop, colour-correct or save with lossy compression between stages.

1

Left band · subtract one value

Add the eight student-number digits, multiply the total by 3, and subtract that value from every red, green and blue value in the left band.

Exact rule

Let d1…d8 be the eight student-number digits.

left shift = 3 × sum(d1…d8)
answer = encoded − left shift
decoded = answer − 256 × floor(answer ÷ 256)

2

Middle band · subtract by colour

Form four two-digit numbers from the student number. Use three simple sums to calculate separate red, green and blue shifts.

Exact rule

p1 = 10d1 + d2; p2 = 10d3 + d4
p3 = 10d5 + d6; p4 = 10d7 + d8

red shift = p1 + p4
green shift = p2 + p4
blue shift = p3 + p4

For each channel, calculate answer = encoded − shift, then use decoded = answer − 256 × floor(answer ÷ 256).

3

Right band · row swaps and subtraction

Within each column, swap rows 1–5 with 6–10, then 11–15 with 16–20, and continue in blocks of ten. Leave a final incomplete block unchanged. Then subtract one value.

Exact rule

Swap complete five-pixel halves for all four channels, including alpha.

right shift = 2 × sum(d1…d8)
answer = swapped − right shift
decoded = answer − 256 × floor(answer ÷ 256)

Apply the subtraction to red, green and blue only.

How to find the three bands

Let q = floor(width ÷ 3) and r = width − 3q. Band 1 has q + 1 columns when r ≥ 1; band 2 has q + 1 columns when r = 2; band 3 receives the rest. Start at column 0.
